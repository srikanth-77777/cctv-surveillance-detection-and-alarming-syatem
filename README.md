# Video Surveillance Project

This repository contains a CCTV video surveillance system with backend and frontend components.

## Contents

- `backend/` - API, detector, notifier, and database integration
- `frontend/` - HTML/CSS/JS interface
- `main.py` - entry point for the surveillance application
- `model/` - trained model artifacts

## Notes

- The Python virtual environment and site packages are excluded from version control via `.gitignore`.
- Large media/data folders such as `videos/` and `uploads/` are also ignored.

## Getting Started

1. Create and activate a Python virtual environment.
2. Install required packages (e.g. TensorFlow, OpenCV).
3. Run `main.py`.

> To publish this project to GitHub, set up a remote repository and push from this local repository.
